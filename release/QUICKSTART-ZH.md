# 浮光 · Windows 快速开始

这是已经构建好的版本。无需 npm install，也不会自动安装软件。

本版包含六种独立花型：牡丹、玫瑰、莲花、向日葵、郁金香和百合。在页面左上方的“花型”中选择，粒子会先散开再组成新花；连续选择以最后一次为准。无需开启摄像头即可体验全部花型。

系统开启“减少动态效果”时，花型直接切换，停止环境转动、呼吸和自动流转；仍可使用绽放、星散、拖动及缩放。

## 打开

1. 把整个 ZIP 解压到普通文件夹。不要直接在 ZIP 压缩包窗口里运行。
2. 双击 `Start.cmd`。
3. 启动器优先使用电脑上已有的 Node.js，其次使用 Python 3。成功后会打开默认浏览器的 `http://127.0.0.1:4173/`。
4. 保持命令窗口打开。使用结束后，在该窗口按 Ctrl+C 停止本地服务。

如果浏览器没有自动打开，请复制命令窗口中的地址。不要双击 `index.html`：file:// 无法可靠加载模块和手势资源，摄像头也需要 localhost 或 HTTPS。

## 电脑还没有 Node.js / Python？

启动器只显示提示，不会安装任何东西。可以自行从官方站点安装 Node.js（建议 22.12 以上版本）或 Python 3，然后重新运行：

- Node.js：https://nodejs.org/
- Python：https://www.python.org/

不需要同时安装二者。已经有任意一种即可运行预构建版。

## 体验与操作

| 输入 | 效果 |
| --- | --- |
| 绽放 / 星散 | 聚合成花 / 散入星尘 |
| 自动流转 | 开启或停止连续聚散演示，无需摄像头 |
| 鼠标 / 单指拖动 | 旋转花朵 |
| 滚轮 / 双指缩放 | 调整大小 |
| 空格 / R / H | 切换聚散 / 重置视角 / 隐藏或显示界面 |

右上角“画质设置”可选择“粒子质量”：默认“自动适配”，根据设备尺寸和持续帧率调整；也可手动选择细腻（100,000 粒子）、平衡（60,000）或轻盈（28,000）。

## 摄像头

点击页面中的“开启手势交互”才会请求摄像头权限。不会请求麦克风。帧只在浏览器本机处理，不录制、不上传。第一次开启需要从当前本地服务读入模型和 WASM；这些文件已包含在压缩包里，无需 Google / jsDelivr。

- 建议使用新版 Chrome 或 Edge
- 点击“取消开启”可取消模型加载；“关闭摄像头”停止媒体轨道
- 摄像头拒绝或不可用时，鼠标和触控仍能操作

右手张开聚合，握拳散开并复位，转动右手手腕旋转；左手开合调整大小；拇指与食指靠拢触发光带扫描。左右手按身体的左右区分，摄像头预览为镜像显示。手掌完整入镜、光线明亮时识别更稳定。

本地服务只绑定 127.0.0.1，不向局域网提供访问。不要把它当作公网服务器。若想正式部署，应使用 HTTPS 静态托管；本包不会自动发布站点或启用 GitHub Pages。

## 端口被占用

关闭之前启动的命令窗口后重试。也可以在当前文件夹的命令提示符中运行：

```bat
set PORT=4174
node server.mjs
```

Python 对应 `py -3 serve.py`。使用新的端口时，浏览器地址也要改成命令窗口显示的地址。
